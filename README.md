# Md. Nasir Uddin — Portfolio (Static)

A simple, responsive portfolio built with **HTML + CSS + JavaScript**.  
Includes fixed header, smooth section scrolling, timeline layout, publications, projects, and social icons.

## Deploy (GitHub Pages)
1. Create a repo, e.g., `nasir-portfolio`.
2. Upload all files (keep folder structure).
3. In **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` (root).
4. Wait for the site to build, then open the given URL.

## Files
- `index.html` — main page.
- `styles.css` — styles (dark/light support, timeline, cards).
- `script.js` — theme toggle, scroll spy, back-to-top.
- `assets/Md-Nasir-Uddin-Resume.pdf` — downloadable CV.
- `assets/images/` — photos and screenshots.
- `favicon.svg` — site icon for tabs.
